# Proyecto-2---IMAX-licitacion

Curso: Bases de Datos, TEC

## Contenido
- `sql/`: scripts de la base de datos (PostgreSQL), en orden numérico
- `concurrencia/`: prueba de doble venta de asientos
- `docs/`: diagramas, capturas y documento técnico

1. Crear la base de datos `imax` en PostgreSQL
2. Ejecutar los scripts de `sql/` en orden (01, 02, 03...)
3. Ejecutar la prueba de concurrencia (instrucciones en `concurrencia/`)
